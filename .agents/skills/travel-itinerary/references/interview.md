# ヒアリングの進め方

## 基本ルール

- **セクションごとに、2〜5 問をまとめて聞く**。1 問ずつ聞くと往復が多くなり、一度に全部聞くと答えにくくなるため
- 質問には番号を付け、**回答の例**を添える。ユーザーは番号ごとに、短く答えればよい
- 「未定」「おまかせ」「スキップ」と答えてよいことを、最初に伝える
  - 「未定」の項目は、しおりにも「未定」と書くか、省略する
  - 「おまかせ」の項目は、AI が提案する。提案した内容は、確認のときに提案であると分かるようにする
- すでに答えが分かっている項目（最初の依頼文に書いてあるなど）は聞き直さない
- 回答があいまいでも、しおりが作れるなら先に進む。細かい点は最後の確認でまとめて聞く

## 最初の質問: 決まっていること

ヒアリングの最初に、**すでに決まっていることを自由に書いてもらう**。

> まず、この旅行ですでに決まっていることはありますか？
> 予約済みの飛行機・新幹線・宿、行くと決めている場所、日程、予算、集合時刻など、何でも書いてください。
> まだ何も決まっていなければ「なし」で大丈夫です。

- 書いてもらった内容は、以降の質問の答えとして扱い、**同じことを聞き直さない**
- 予約済みのもの（便名・時刻・宿の名前など）は、そのまましおりに載せる。AI が勝手に変えない
- 以降のセクションでは、まだ分かっていない項目だけを聞く。セクションの質問がすべて埋まっていれば、そのセクションは飛ばす

## セクション 1: 基本情報（必須）

1. 旅のタイトル（例: 「夏の北海道旅行 2026」。おまかせ可）
2. 行き先（例: 札幌・小樽）
3. 日程（例: 2026/08/10〜08/12、2 泊 3 日）
4. メンバー（例: 大人 4 人。幹事・運転担当など役割があれば。名前はニックネームで OK）
5. 移動手段（例: 行きは羽田 7:30 集合 → 8:30 発の飛行機、現地はレンタカー）
6. 宿泊先（例: 1 泊目は札幌駅周辺のホテル、2 泊目は小樽の旅館。未定可）

## セクション 2: 予算

1. 1 人あたりの予算（例: 8 万円くらい。「なるべく安く」「特に決めていない」でも可）
2. 予算に含めるもの（例: 交通費・宿泊費・食事・観光・おみやげ。交通費と宿は別、など）
3. お金をかけたいもの・抑えたいもの（例: ごはんは贅沢に、宿は安くていい）
4. 支払い・精算の方法（例: 現地は会計のさくらがまとめて払い、あとで割り勘。スキップ可）

- 予約済みの交通・宿の金額が分かっていれば、それをもとに内訳（`budget.breakdown`）を作る
- 分からない金額は、行き先・時期・人数から**目安**を出してよい。その場合は `budget.note` に「目安」と書き、確認のときにも目安だと伝える
- 予算は、日程案の作成（セクション 3）にも使う。予算を超えそうなプランは提案しない

## セクション 3: 日程・プラン

1. 日ごとの予定（時刻・場所・やること。決まっているところだけで OK）
2. 行きたい場所・食べたいもの・やりたいこと
3. 集合場所・集合時刻（まだ分かっていなければ）

- 予定が決まっていない日があれば、「行きたい場所」と予算をもとに **AI が日程案を作るか**聞く
- 日程案を作るときは、移動時間・営業時間・食事の時間を考えて、無理のない時刻にする

## セクション 4: オプション

最初に、どれを入れるかをまとめて聞く（複数選択）:

| オプション | 入れる場合に聞くこと |
|------------|----------------------|
| ☔ 雨天時のプラン | どの日に用意するか、屋内で行きたい場所があるか（おまかせ可） |
| 🎒 持ち物リスト | 特別に必要なもの（水着・スキー用品など）、みんなで 1 つあればよいものと担当者 |
| ☀️ 天気 | 追加の質問はなし（調べ方は SKILL.md の「天気」を参照） |
| 📖 参考ブログ | 特に知りたいこと（グルメ・子連れ・穴場など）。Web 検索で記事を探し、参考ブログのタブにまとめる |
| 📝 緊急連絡先・メモ | 宿の連絡先、注意事項（持病・アレルギーなどを載せるかも確認） |

- 持ち物リストは、行き先・季節・日数・アクティビティをもとに AI が基本の項目を作り、ユーザーの回答を足す
- 雨天プランは、`days` の同じ日の予定をもとに、屋内の代わりの場所を提案する。しおりでは、その日の日程の中で「晴れ / 雨天」を切り替えて表示される（別のタブにはならない）

## 最後の確認

しおりを作る前に、集めた内容を短くまとめて見せる:

```
## しおりの内容
- タイトル: 夏の北海道旅行 2026
- 行き先 / 日程: 札幌・小樽 / 8/10（月）〜 8/12（水）
- メンバー: 4 人
- 予算: 1 人 8 万円（交通・宿・食事・観光込み。食事・観光は目安）
- タブ: 概要 / 日程（8/11 は雨天プランに切り替え可）/ プラン / 参考ブログ / 天気 / 持ち物 / メモ
- AI が提案した部分: 2 日目の午後の予定、雨天プラン、持ち物リストの基本項目

この内容でしおりを作ってよいですか？ 直したいところがあれば教えてください。
```

OK をもらってから JSON を書く。
