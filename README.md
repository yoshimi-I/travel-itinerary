# Travel_itinerary 🧳

> AI エージェントと対話するだけで、メンバーに配れる「旅のしおり」を HTML で作るツール

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
![Status](https://img.shields.io/badge/status-WIP-orange)

**Claude Code / Codex / Kiro** に対応した、旅のしおり作成用のエージェント向けプロンプト集です。
AI が行き先・日程・メンバー・プランなどを順番に質問し、その回答をもとに、タブで切り替えられる 1 枚の HTML のしおりを生成します。

> [!NOTE]
> 現在開発中です。Claude Code と Codex に対応済みで、Kiro は今後対応予定です。

👉 サンプル: [`examples/sample-trip.html`](examples/sample-trip.html)（ダウンロードしてブラウザで開くと確認できます）

---

## ✨ 特徴

- **質問に答えるだけ** — AI が必要な情報を 1 つずつ聞いてくれるので、白紙から書く必要がありません
- **タブ切り替えの HTML** — 日程・プラン・天気・持ち物などをタブで整理し、スマホでも見やすく表示します
- **メンバーに配布できる** — 外部ファイルに依存しない 1 ファイルの HTML なので、送るだけで開けます
- **参考ブログを探してくれる（オプション）** — AI が Web で行き先のブログや記事を探し、実際に開いて確かめたものだけを「参考ブログ」タブにまとめます
- **雨天時のプランにも対応（オプション）** — 希望すれば雨の日の代わりのプランも質問し、日程の中で「晴れ / 雨天」をボタンで切り替えられるようにします
- **複数のエージェントに対応** — Claude Code / Codex に対応済み（Kiro は今後対応）

## 🤖 対応エージェント

| エージェント | 状態 | 配置先 | 呼び出し方 |
|--------------|------|--------|------------|
| Claude Code | ✅ 対応 | `.claude/skills/travel-itinerary/` | `/travel-itinerary` |
| Codex | ✅ 対応 | `.agents/skills/travel-itinerary/` | `$travel-itinerary` |
| Kiro | 🚧 今後対応 | `.kiro/steering/` | — |

skill の本体（質問の流れ・JSON の仕様・HTML テンプレート・ビルドスクリプト）は `.agents/skills/travel-itinerary/` にまとめてあります。Claude Code 用の skill は、この本体を読んで従う薄い入口です。

どちらも「旅のしおりを作りたい」と話しかければ、内容から自動で skill が選ばれます。

## 🚀 使い方

1. このリポジトリを clone します

   ```bash
   git clone https://github.com/yoshimi-I/Travel_itinerary.git
   cd Travel_itinerary
   ```

2. 使うエージェントを起動し、しおり作成を依頼します

   | エージェント | 依頼の仕方 |
   |--------------|------------|
   | Claude Code | `/travel-itinerary`、または「旅のしおりを作りたい」 |
   | Codex | `$travel-itinerary`、または「旅のしおりを作りたい」 |

3. AI の質問に答えていきます（最初に「決まっていること」を聞かれ、そのあと基本情報 → 予算 → 日程・プラン → オプションの順に、まだ分からないことだけをまとめて聞かれます）
4. `output/<旅の名前>/index.html` にしおりが生成されるので、ブラウザで開いて確認します
5. 直したいところがあれば、AI に伝えると作り直してくれます
6. 内容がよければ、メンバーに配ります

> [!TIP]
> HTML のビルドには Python 3（標準ライブラリのみ）を使います。Python がない環境では、AI がテンプレートに直接データを埋め込みます。

## 💬 ヒアリング項目

### 最初に: 決まっていること

「すでに決まっていることはありますか？」と最初に聞かれます。予約済みの便や宿、行く場所、予算などを自由に書けば、その内容はしおりにそのまま反映され、同じことは聞き直されません。

### 基本（必須）

| 項目 | 例 |
|------|----|
| 旅のタイトル | 夏の北海道旅行 2026 |
| 行き先 | 札幌・小樽 |
| 日程 | 2026/08/10〜08/12（2 泊 3 日） |
| メンバー | 大人 4 人 |
| 移動手段 | 飛行機（羽田 ⇄ 新千歳）、現地はレンタカー |
| 宿泊先 | 1 泊目: 札幌駅周辺、2 泊目: 小樽 |

### 予算

| 項目 | 例 |
|------|----|
| 1 人あたりの予算 | 8 万円くらい |
| 予算に含めるもの | 交通費・宿泊費・食事・観光 |
| お金をかけたいもの・抑えたいもの | ごはんは贅沢に、宿は安く |
| 支払い・精算の方法 | 会計担当がまとめて払い、あとで割り勘 |

分からない金額は AI が目安を出し、しおりの概要タブに内訳として載せます。

### プラン

| 項目 | 例 |
|------|----|
| 日ごとの予定 | 時刻・場所・やること |
| 行きたい場所・食べたいもの | 白い恋人パーク、海鮮丼 |
| 集合場所・集合時刻 | 羽田空港 第 2 ターミナル 7:30 |

### オプション

| 項目 | 内容 |
|------|------|
| 雨天時のプラン | 雨の日の代わりの予定を作り、日程タブで晴れの予定と切り替えられるようにします |
| 持ち物リスト | 全員の共通の持ち物と、各自で用意するものを分けて作成します |
| 天気 | 行き先・日程から、天気の目安を載せます |
| 参考ブログ | 行き先や行く場所のブログ・記事を Web で探して載せます（Web 検索が使えるエージェントのみ） |
| 緊急連絡先・メモ | 病院・現地の連絡先、注意事項など |

## 📄 生成されるしおり

タブで切り替えて表示する 1 枚の HTML です。

| タブ | 内容 |
|------|------|
| 🗺 概要 | タイトル、行き先、日程、メンバー、集合場所・集合時刻 |
| 📅 日程 | 日ごとのタイムスケジュール。雨天プランがある日は「晴れ / 雨天」で切り替えられます |
| 📍 プラン | 観光スポット・食事処の詳細、地図リンク |
| 📖 参考ブログ | 行き先・行く場所ごとの参考記事（タイトル・サイト名・要約・リンク） |
| ☀️ 天気 | 日ごとの天気の目安、服装のアドバイス |
| 🎒 持ち物 | チェックできる持ち物リスト |
| 📝 メモ | 緊急連絡先、注意事項など |

### 天気について

- 出発日が近い場合は、天気予報を調べて反映します（Web を検索できるエージェントの場合）
- 出発日まで日がある場合は、その時期の平年の気候を目安として載せます
- 出発前に最新の予報を確認できるよう、天気予報サイトへのリンクも載せます

## 🛠 しくみ

```
質問に答える → AI が itinerary.json を書く → build.py がテンプレートに埋め込む → index.html
```

デザインとタブは固定のテンプレートで描画し、AI はデータ（JSON）だけを書きます。そのため、どのエージェントで作っても同じ見た目になります。JSON の仕様は [`schema.md`](.agents/skills/travel-itinerary/references/schema.md) を参照してください。

手動でビルドする場合:

```bash
python3 .agents/skills/travel-itinerary/scripts/build.py examples/sample-trip.json output/sample/index.html
```

```
├── examples/                          # サンプルのしおり（架空のデータ）
└── output/                            # 生成したしおり（git 管理外）
```

## 🔒 個人情報について

しおりには、氏名・電話番号・予約番号などの個人情報が入ることがあります。

- 生成したしおりは `output/` に保存され、git では管理しません
- しおりを公開する前に、個人情報が入っていないか確認してください
- このリポジトリに含めるサンプルには、架空の情報だけを使います
